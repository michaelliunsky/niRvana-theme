# Основные возможности темы

**Оформление и просмотр**

- **Тёмная тема** — три режима: светлый, тёмный и системный (по умолчанию — как в ОС).
- **Слайдеры** — 8 встроенных стилей слайдера (3D cover flow, плоский, плоский поток карточек, поток изображений, фон из шапки статьи и другие); главная страница и страницы рубрик настраиваются независимо.
- **Загрузка без перезагрузки** — асинхронная подгрузка статей с возможностью глобального включения и отключения.
- **Оглавление статьи** — автоматически находит заголовки h2/h3 и выводит оглавление рядом с боковой панелью.
- **Фиксированная боковая панель** — по желанию закрепляет боковую панель на статьях и страницах при прокрутке.
- **Виджеты боковой панели** — настраиваемое количество боковых колонок, разработаны специальные виджеты под возможности темы.

**Написание и контент**

- **UI-блоки** — 10 контентных блоков и 4 блока-виджета (подсказки, спойлеры, выпадающие меню, модальные окна, кнопки скачивания, карусели, подборки статей, «после комментария», видео с Bilibili и другое), вставляются прямо в редакторе.
- **Микроблог (заметки)** — короткие публикации, позволяющие записывать мысли в любое время и в любом месте.
- **Подсветка кода** — автоматическая подсветка кода в статьях с копированием в один клик.
- **Бейджи на миниатюрах** — настраиваемый текст и цвет бейджа на миниатюре записи.

**Взаимодействие с читателями**

- **Эмодзи в комментариях** — тема содержит встроенный набор смайлов для комментариев; настраивается в админ-панели без дополнительных плагинов.
- **Лайки** — каждая статья поддерживает кнопку «Нравится»; можно вывести список самых популярных статей по лайкам (администратор может корректировать количество лайков в админке).
- **Скрытый контент** — скрывайте часть содержимого до первого комментария, стимулируя взаимодействие с читателем (можно также требовать регистрацию и вход, чтобы открыть содержимое).
- **Скачивание после комментария** — можно настроить отображение ссылки на скачивание только после того, как пользователь оставит комментарий.
- **Озвучивание** — встроенная функция голосового чтения, которая прочитает для вас статьи вслух.

**Поделиться и поддержать**

- **QR-код обложки** — для каждой статьи автоматически генерируется QR-код, которым можно поделиться в WeChat и других соцсетях.
- **Донаты** — поддержка автора несколькими способами: QR-коды Alipay, WeChat, ссылка PayPal.

**Управление сайтом**

- **Автообновления темы** — встроенная проверка обновлений: новые версии устанавливаются прямо из админки.
- **Мультиязычность** — установите плагин [niRvana-translate](https://github.com/michaelliunsky/niRvana-translate) и пользуйтесь мгновенным переключением между языками.

# Установка

Требования: **Лучшая совместимость с PHP 8.3**

Скачайте .zip файл со страницы [Release](https://github.com/michaelliunsky/niRvana-theme/releases) и загрузите/установите его через страницу «Темы» в админке WordPress.

**Тема включает электронные письма с ответами на комментарии. Если вам нужна автоматическая отправка уведомлений по электронной почте о ответах на комментарии, установите плагин WP-SMTP или настройте отправку почты самостоятельно. Если эта функция не нужна — никаких действий не требуется.**

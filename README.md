# 主题基本特性

- **不刷新加载** - 异步加载文章，支持全局开关
- **滚动图** - 内置 8 种滚动图风格（3D 封面流、扁平、扁平卡片流、滚动图片、头图背景等），首页与分类页可独立配置
- **UI 样式区块** - 内置 10 种内容区块与 4 种小工具（提示框、折叠、下拉菜单、模态框、下载按钮、轮播、文章展示、回复可见、B站视频等），编辑器内直接插入
- **语音朗读** - 集成语音朗读功能来为您阅读文章
- **说说功能** - 简短说说功能，随时随地记录您的想法
- **打赏** - 允许通过多种途径打赏，如：支付宝二维码、微信二维码、PayPal 链接
- **点赞** - 每篇文章均提供点赞功能，可展示访客最喜欢的文章列表（后台可以修改点赞数据）
- **生成封面二维码** - 每篇文章均可生成二维码用于分享到微信等社交平台
- **深色模式** - 支持手动切换与按时间段自动切换
- **文章目录** - 自动识别文章中的二级/三级标题，生成目录浮动显示在边栏
- **代码高亮** - 文章内代码自动高亮，支持一键复制
- **侧边栏小工具** - 边栏数量可自定义，内置博主信息、标签云、轻博客、热门文章小工具
- **卡片-角标** - 文章缩略图可配置角标文字与颜色
- **固定侧边栏** - 可选文章/页面侧边栏在滚动时固定显示
- **评论表情** - 本主题自带评论表情功能，无需插件在后台即可设置
- **多语言** - 安装[niRvana-translate 多语言翻译插件](https://github.com/michaelliunsky/niRvana-translate)，享受极速多语言切换
- **回复下载** - 可设置要求用户评论文章后才提供下载地址
- **内容回复可见** - 指定某些内容需要读者评论后才可查看，让读者与你互动（可设置为要求用户注册登录并评论后才显示某些内容）
- **主题自动更新** - 内置自动更新检查，新版本发布后可在后台直接更新

# 安装

环境要求：**PHP8.3 兼容最佳**

在 [Release](https://github.com/michaelliunsky/niRvana-theme/releases) 页面下载 .zip 文件，在 WordPress 后台 "主题" 页面上传并安装。

**主题自带评论邮件回复，如果您需要评论回复自动邮件提醒功能，请安装 WP-SMTP 插件，或自行配置邮箱发送，如果不需要，则不需要采取操作**
